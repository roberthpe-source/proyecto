Caracteristicas principales de las tecnologías web

HTML

es un lenguaje de marcado que permite organizar y estructurar el contenido de una página web mediante etiquetas. Con él se pueden incorporar títulos, párrafos, imágenes, enlaces, tablas y formularios.

CSS

es un lenguaje de hojas de estilo que permite definir la apariencia visual de una página web. Con él se pueden establecer colores, fuentes, tamaños, márgenes, bordes y otros aspectos estéticos.

PHP

es un lenguaje de programación del lado del servidor que permite crear páginas web dinámicas y interactuar con bases de datos. Con él se pueden procesar formularios, manejar sesiones, autenticar usuarios y realizar otras tareas del lado del servidor.

SQL

es un lenguaje de consulta estructurada que permite gestionar y manipular bases de datos relacionales. Con él se pueden realizar operaciones de inserción, actualización, eliminación y consulta de datos.
